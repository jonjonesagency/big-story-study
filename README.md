# The Big Story: How the Bible Leads to Jesus

A static study guide for a Friday men's Bible study (5 sections, 21 sessions).
Plain HTML/CSS/JS, no build step. Publish by enabling GitHub Pages on the repo root.

- `index.html`, `style.css`, `app.js`: the site
- `data.js`: all session content (openers, questions, takeaways, leader tips, video IDs)
- `videos/`: Jon's intro videos for Section 1 (720p MP4) and poster images

Link to a session directly with `#s<section>-<session>`, e.g. `#s2-4`.
BibleProject videos are embedded from BibleProject's official YouTube channel.
